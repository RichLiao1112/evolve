# 关于 Evolve

Evolve 是一个公开分享站点，用来沉淀我在 **AI Agent、自动化、工具使用、网站方案、以及生活与创作系统** 上的长期思考与实践。

它的目标不是做资讯聚合，也不是追热点，而是把一些值得长期回看的内容整理成更稳定、可引用、可复用的页面。

## 这个站点主要写什么

目前内容主要分成几类：

- **Hermes 相关文档**：围绕 Hermes Agent 的配置、工具、平台接入与使用经验
- **报告 / 方案**：对项目、系统、自动化闭环、AI 工作流的分析与整理
- **生活板块**：记录系统、通勤、相机、创作与长期表达相关内容

## 这个站点不做什么

为了让内容保持可读性，Evolve 不追求：

- 高频转载
- 情绪化标题党
- 大量低信息密度内容
- 影响阅读体验的高干扰广告样式

## 更新原则

Evolve 更偏向“持续沉淀型”更新，优先发布：

1. 真实使用后形成的方法论
2. 可复用的配置与工作流
3. 能长期带来参考价值的文章
4. 对外可分享、可回看、可继续扩展的结构化内容

## 关于合作 / 赞助

站点未来可能会出现 **赞助位、合作支持位、工具推荐位**，但会尽量遵守几个原则：

- **优先相关性**：尽量只展示与页面主题相关的产品、服务或合作信息
- **优先可读性**：不使用明显破坏阅读体验的弹窗、遮挡层、自动播放等形式
- **优先标识清楚**：赞助或合作内容会尽量进行明确标识
- **优先克制**：宁可少放，也不把页面做成广告墙

## 站点归属与说明

Evolve 为个人维护的公开站点，页面内容主要代表作者在特定时间点的观察、经验与判断，不构成专业法律、财务、医学或投资建议。
