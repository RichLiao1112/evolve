# 项目概述

Flipbook 是由 **Zain Shah（@zan2434）** 与一小团队在 X（原 Twitter）上公开预览的实验性项目。核心理念是 **摆脱传统 HTML/CSS 布局引擎**，让 **生成式图像模型直接渲染屏幕上的每个像素**，实现 **实时、全像素的交互式 UI**。项目被描述为 “a house of cards of APIs and open models tied together with duct tape”。

官方演示页面（常被引用）为 **https://flipbook.page/**，该页面的公开描述如下（摘自搜索结果）：

> All text on the screen is rendered as pixels by the image model. The information in the images comes from a combination of an agentic web search and the image model's own world knowledge. The live video stream is an experimental feature that turns the static images generated by our system into a more continuous video stream.

项目目前仍处于 **原型/预览阶段**，社区反馈热烈（单条推文 700+ 点赞、55 条回复），并已提供 **可直接访问的 Demo** 链接（embed 在 X 线程中）。

## 2. 使用说明（基于官方 Demo 页面）

### 2.1 访问演示

- 直接打开 **https://flipbook.page/**（浏览器会加载一个全屏 Canvas），页面会自动展示实时渲染的示例页面。
- 若想观看 **视频流演示**，在页面底部点击 “Live video stream (experimental)” 按钮，系统会启动后端的 **video generation model**，将静态帧转换为连续视频。

### 2.2 本地快速体验（假设已有源码）

```bash
# 克隆（示例）
git clone https://github.com/zan2434/flipbook.git
cd flipbook

# 安装依赖（Python 3.11+）
pip install -r requirements.txt

# 启动后端（需要配置 Modal/LTXStudio API Key）
export MODAL_TOKEN=YOUR_MODAL_TOKEN
export LTX_API_KEY=YOUR_LTX_KEY
python -m flipbook.backend.server

# 打开前端（默认 http://localhost:8000）
python -m http.server 8000 --directory flipbook/frontend
```

### 2.3 关键配置参数

| 参数 | 含义 | 示例 |
|------|------|------|
| `MODAL_TOKEN` | Modal 云 GPU 计算资源的访问令牌 | `sk-xxxx` |
| `LTX_API_KEY` | LTXStudio 视频模型的 API Key | `ltx_abcdef` |
| `SEARCH_ENDPOINT` | 用于“agentic web search”的后端（可选） | `https://serpapi.com` |

> **注意**：当前版本仅支持 **英文字体** 的渲染，中文渲染可能出现文字错位或缺失。

## 5. 优缺点速评

**优势**
1. **创新的 UI 渲染方式**：完全摆脱前端布局代码，展示了生成式模型在 UI 场景的潜力。
2. **高度实验性**：快速迭代的原型展示了 AI+前端的可能新范式。
3. **开源/可复现**（若源码公开），可以直接复用已有的 API 调用链路。

**局限**
1. **文字渲染不可靠**：模型对文本的精准度仍低于传统字体渲染。
2. **资源消耗大**：每帧图像生成需要高性能 GPU（Modal、LTXStudio），成本较高。
3. **生态不完整**：缺少官方 SDK、文档和成熟的社区工具链。
